# 论文调研与结构选择依据

> 2026 年 11 月 5 日。用于解释主报告的结构取舍；不是独立实验结果。调研方式为核对原论文公开内容、方法与消融相关段落，以及官方模型配置，不将搜索摘要或第三方博客作为性能证据。覆盖的是与题目最相关的公开研究，不保证穷尽所有同期工作。

## 1. 上一版为什么容易与其他答案相似

截图中的结构和初版都落在 ModernBERT 的常见设计空间：Pre-LN、GeGLU、RoPE、局部窗口与周期性全局层。题目又明确要求约 3 亿参数、8K，自然会使配置收敛。但 24 层、896 维、14 个头并非约束唯一决定的答案，初版对这些数字的论证主要是参数配平，缺少任务机制依据。

仅凭结构表无法判断作者、AI 型号或是否复用了提示词。更合理的改进是把默认配置当基线，寻找可解释的任务冲突，并给出能够否决新结构的实验。主报告因此不再以尺寸表作为核心贡献。

## 2. 现代多语起点：为什么改选 mmBERT

- [mmBERT 原论文](https://arxiv.org/abs/2509.06888)提供与本题相近的公开编码器；[官方配置](https://huggingface.co/jhu-clsp/mmBERT-base/blob/main/config.json)可核对实际维度与 attention 周期。
- [mGTE](https://arxiv.org/abs/2407.19669)仍是有价值的比较对象，尤其适合观察不同容量分配和预训练历史下的任务表现。
- [EuroBERT](https://arxiv.org/abs/2503.05500)说明现代多语编码器已有其他系统路线，但“多语”并不自动等于“对中英四任务最适合”。不以语言数或榜单均值直接决定起点。

选择 mmBERT 的理由是它能让本文直接研究 ModernBERT 风格结构的改造，并保留现成双语知识。选择不是因为它已经在本实验中击败 mGTE。若实际中文抽取基线明显不足，需重新评估起点；不能用后续结构改造掩盖底座不匹配。

## 3. 摘要分支最接近哪些已有工作

### LongT5：直接的机制先例

[LongT5](https://arxiv.org/abs/2112.07916)的 transient global attention 已使用临时块摘要，让局部 token 访问更大范围。因此“把局部窗口加上段落摘要”本身不新。

本文与之相关的改造是：在现成双向编码器中只替换部分原全局层；保留直接全局路径；比较均值与双槽池化；使用单独归一化的局部／摘要分支并门控融合。它们是需要验证的迁移和组合，不能称为完整复现 LongT5，也不能靠命名声称首次。

最近对照：单均值摘要＋固定混合权重。若这个简单对照已经达到同等质量与成本，就删去复杂结构。

### HAT 与 HDT：层次结构的依据与局限

[HAT](https://arxiv.org/abs/2210.05529)研究了段内、跨段编码的安排；[HDT](https://arxiv.org/abs/2407.08330)使用文档层级和 anchor token。它们提示跨段通信值得在中间层发生，而非只在最末端汇总。

本文不要求输入拥有可靠的句子—章节树：主实验用固定 token 块，降低中文分句、网页结构解析和 kernel 不规则性带来的混杂。代价是失去语义边界。必须通过块边界偏移和不同块长测试，判断这种简单化是否伤害抽取。

固定 token 块不是优于语义结构的已知结论。若论文级后续研究预算允许，可在结构可靠文档上加入段落划分对照。

### NSA、MoBA 与 Landmark：为什么暂不做硬路由

[NSA](https://arxiv.org/abs/2502.11089)将压缩和细粒度选择结合；[MoBA](https://arxiv.org/abs/2502.13189)按块选择 attention；[Landmark Attention](https://arxiv.org/abs/2305.16300)通过 landmark 支持相关块访问。它们共同提醒：摘要和原始细节路径并不是新的研究组合方向。

本文暂不让摘要决定硬 top-k token/block 路由。原因是错误路由会令关键证据不可见，训练和实现也更复杂；在 8K、约 3 亿和单卡课程预算下，需要先证明简单摘要是否有用。这是范围判断，不是认为软摘要优于上述方法。若细节诊断反复失败，再研究路由访问原始块，并将其作为新阶段计费。

## 4. 为什么索引输出也必须改变与消融

[Late Chunking](https://arxiv.org/abs/2409.04701)已给出全文编码、后分块池化的方法。因此主报告强制包含“原始 mmBERT＋late chunking”，不允许只与单向量比较。

[ConTEB／InSeNT](https://aclanthology.org/2025.emnlp-main.1150/)则提醒：全文背景可能帮助指代，也可能让同一篇文档的不同片段过度相似。本文用文档命中和证据块定位两个指标，并且仅把已确认不相关的同文档块当负例。

[ColBERTv2](https://arxiv.org/abs/2112.01488)与[BGE-M3](https://arxiv.org/abs/2402.03216)支持细粒度相关性建模，但不能忽略其表示与索引成本。本文选择最多 32 个块向量作为较小输出方案；这仍不是免费，且不保证能替代 token-level late interaction。

关键判别：若原主干采用相同块输出后已经解释全部增益，就只能得出“任务输出结构有用”，不能得出“新 attention 主干有用”。

## 5. 查询全局通道的归属与作用

[Longformer](https://arxiv.org/abs/2004.05150)已采用任务相关全局 token。本文在重排中让 query 与全文直接交流，是这一方向的合理应用。不能把它写作新注意力算法。

它补的是离线检索无法提供的条件化交互。文档建库始终不带 query；在线重排允许 query 影响 document 表示。与[Poly-encoders](https://arxiv.org/abs/1905.01969)一样，相关工作早已探索独立编码与充分交互之间的质量—效率取舍，本文不主张首次发现这一矛盾。

对照必须固定候选和 scoring head。若新增通道只是增加计算而未改善远距证据匹配，最合理结果是删除，而不是再增加一个 loss 为它解释。

## 6. 可以怎样陈述本项目贡献

在实验前：

> 我提出一个约 3 亿参数编码器的结构改造假设，研究部分全局交互能否被低成本摘要替代，并用 token 细节保留、块证据检索和查询条件化重排来检验这种取舍。

实验支持后，才能补充具体收益、计算量和适用范围。可能成立的贡献包括：发现可迁移的替换层安排；证明门控在稀有事实条件下确有作用；或证明某种压缩对抽取不利并给出可复现边界。

不能预先陈述的内容包括：首次提出分层 attention；首创局部与全局结合；比所有现代编码器更强；仅凭更低 MLM loss 证明理解更好；把现有方法重新命名当作创新。

如果最终只有“原模型＋成熟任务头”有效，也是一项有价值的负结果。课程作业的独立思考体现在问题分解、合理结构和证据标准，不由配置表与别人有多少数字不同决定。
